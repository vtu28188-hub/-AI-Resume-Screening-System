# AI Resume Screening System

An AI-powered Resume Screening System built using Python, Streamlit, TF-IDF, and Cosine Similarity.

## Features

- Upload Resume (PDF)
- Enter Job Description
- Resume Match Score
- ATS Score
- Candidate Details
- Skill Matching
- Missing Skills
- Resume Statistics
- Download Report

## Technologies Used

- Python
- Streamlit
- PDFPlumber
- Scikit-learn
